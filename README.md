# Woningencheck.nl

Woningencheck.nl is een Nederlandstalige woningverhuurcheck voor particuliere verhuurders. De applicatie is opgezet als eenvoudige browsertool en gebruikt de actuele projectbasis voor regelgeving, gemeentelijke informatie en bronnen.

## Website

Beoogd domein: woningencheck.nl

## Belangrijk

De tool is bedoeld als praktische eerste controle en niet als vervanging van juridisch of fiscaal advies. Wet- en regelgeving en gemeentelijke regels kunnen wijzigen en moeten periodiek tegen officiële bronnen worden gecontroleerd.
